# 阿米娅桌宠 (AmiyaPet - Android 版)

本项目是原 PC 端《明日方舟阿米娅桌宠》完全针对 Android 平台原生重构的独立应用（另起炉灶，不依赖原 PC 端代码），支持系统悬浮窗常驻桌面互动、角色无缝切换、多手势交互、实时对话气泡与 GPU 绿幕抠图透明渲染。

---

## 核心架构与技术实现

| 模块 | 实现方案 | 说明与优势 |
| :--- | :--- | :--- |
| **主界面 (UI)** | Jetpack Compose + Material 3 | 舟味深色工业美学风格，权限引导、角色切换、动作速率平滑调节 |
| **悬浮窗层** | `SYSTEM_ALERT_WINDOW` (`TYPE_APPLICATION_OVERLAY`) | `WindowManager` 独立层级管理，支持悬浮穿透与自由拖拽 |
| **动作视频渲染** | OpenGL ES 2.0 (`GLSurfaceView` + 自定义着色器) | 专为移动端设计的 **GLSL Chroma-Key 绿幕/黑底抠图着色器**，GPU 实时片元计算与边缘平滑，实现超低 CPU 与电池消耗 |
| **视频解码** | Android 原生硬件加速 `MediaPlayer` | 直接流式读取 `assets/` 中的 WebM 资产，无需解压释放临时文件 |
| **手势与吸附** | `PetTouchHandler` | 智能防抖区分单击/双击/拖拽，松手后带减速插值器自动贴附至屏幕边缘 |
| **对话气泡** | `PetBubbleView` | 自定义透明卡片气泡，支持淡入淡出动画、自动定时退隐与点击关闭 |
| **功耗与保活** | 前台服务 + 屏幕广播监听 | 锁屏/熄屏时自动挂起解码与着色器，**实现 0% 息屏功耗** |

## 手机端交互指南

1. **单击角色**：触发反应动作（害羞、疑惑、得意等随机交互动作）。
2. **双击角色**：向博士打招呼并弹出对话气泡台词。
3. **手指拖拽**：按住角色即可在屏幕任意位置拖拽移动，松手后优雅弹射贴附到最近屏幕边缘。
4. **长时放置**：进入待机后根据配置时间自动从站立过渡到坐下（sit），最后进入睡眠（sleep）。
5. **动作调速**：在应用设置界面提供 0.5x ~ 2.0x 动态滑块，随心调节动作帧率流畅度。
6. **通知栏快捷控制**：常驻通知栏提供「切换角色」与「收回桌宠」一键快捷操作。

## 快速安装与运行

APK 编译产物已生成至：
- `dist\AmiyaPet-v1.0.0-debug.apk` (约 177 MB，完整内嵌阿米娅、泳装安洁莉娜、泳装初雪全部 WebM 动作资产)

### 安装到手机：
```powershell
# 开启手机 USB 调试后执行：
adb install -r dist\AmiyaPet-v1.0.0-debug.apk
```
或者直接将 `dist\AmiyaPet-v1.0.0-debug.apk` 传输到手机微信/QQ/文件管理中直接点击安装。

### 首次使用权限配置：
1. 打开应用，点击顶部的 **「前往系统授权」**。
2. 在系统设置列表中找到并允许「阿米娅桌宠」的 **「显示在其他应用上层」** 权限。
3. 返回应用，开启 **「唤醒桌宠」** 开关，阿米娅即可跃然于手机桌面！

## 本机编译构建

本项目已完全适配离线 Gradle 与 Android SDK 构建工具链：

```powershell
# 一键编译 Debug APK（自动使用本机环境）：
.\tools\build.ps1
```
产物将自动输出到 `app\build\outputs\apk\debug\app-debug.apk`。

## 如何添加新角色

资产结构 100% 兼容原 PC 规范。如需添加新干员：
1. 在 `app/src/main/assets/characters/<角色标识>/` 下放入 `config.json` 及各动作文件夹（内含 `.webm` 视频）。
2. 在 `MainActivity.kt` 的 `availableChars` 列表中加入角色显示名称即可。
