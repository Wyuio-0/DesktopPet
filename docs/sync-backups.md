# 同步备份与恢复

PC、Android 和 iOS 在接收 `replace` 覆盖同步时，会先备份请求涉及的课表、考试、便签。未提供的类别不进入这次备份；普通 `merge` 合并不创建备份。数据格式验证发生在创建备份和修改数据之前。

## 使用方法

打开跨端同步设置中的“备份与恢复”或“本机备份与恢复”。列表显示备份时间、覆盖前或恢复前、涉及的类别。选中备份并确认后，仅恢复列出的类别。恢复前会先为这些类别保存当前状态；若保存失败，恢复取消。

例如，只覆盖便签后产生的备份仅包含便签。恢复它不会撤销此后对考试或课表的修改。恢复含考试的 PC 备份也不会删除作业。备份保留本平台的本地信息，如课表提醒设置、周起始日、调课安排，以及 PC 考试的完成状态和提醒信息。

## 存储与校验

- 备份存放在各端应用数据目录的 `sync_backups` 文件夹。PC 使用用户配置目录，Android 使用应用私有 `filesDir`，iOS 使用应用 Documents 目录。
- 正常保留最近 10 份，每份最大 16 MiB。新备份通过临时文件原子替换落盘，重新读取校验后才允许覆盖，并清理超额旧备份。写入、校验或清理失败均取消本次覆盖；清理失败可能暂留额外一份，后续覆盖也会因超额而停止。
- 内容限定为学业数据和对应本地字段，不打包 API 配置、配对凭据、聊天记录或任意用户指定文件。
- 使用版本号、平台标识和 SHA-256 检查内容完整性。损坏、平台不兼容或路径标识不合法的备份不能恢复。SHA-256 用于发现损坏，不提供加密或恶意篡改认证；备份文件包含本机学业明文数据。
- 备份列表和恢复操作仅在本机提供，没有网络恢复接口，也不支持跨平台导入备份。

## 失败与恢复边界

备份无法安全保存时，覆盖在修改学业数据前停止。三端同步服务对存储失败返回加密的 HTTP 507；格式错误仍返回加密的 400。

备份完成后的学业数据写入仍涉及多个文件，不是跨文件事务。磁盘故障或断电可能导致部分类别已经更新。此时应检查本机存储，再从备份列表手动恢复；本轮没有加入启动时自动回滚或跨文件事务日志。自动备份也不能替代设备丢失、卸载或整个磁盘损坏时需要的独立外部备份。

## 验证

PC 自动测试覆盖恢复原数据及本地字段、按类别恢复、保留后来新增的作业、备份失败取消覆盖与恢复、损坏校验、大小限制、路径限制和保留数量。Android 独立验收包增加同类原生用例，并验证加密 HTTP 存储失败响应。iOS CI 运行本地备份完整性与保留规则检查，并构建原生应用；尚无 iOS 真机验收。

2026-11-15，vivo V2199A / Android 14 的独立 USB 真机验收 **37 / 37 通过**，见 [脱敏记录](acceptance/android-sync-backups-2026-11-15.json)。覆盖按类别恢复、恢复前备份、课表本地设置与调课安排、损坏备份拒绝、存储失败取消覆盖及加密 507 响应、保留数量上限和 PC 恢复往返。本次通过 ADB 转发 TCP，不代表 Wi-Fi LAN 验收；未读取或更改正式应用数据。
