# AmiyaPet-iOS (阿米娅桌宠与学业助手 · 苹果 iOS 原生版)

AmiyaPet-iOS 是专为 iPhone / iPad 设计的罗德岛阿米娅公开领袖桌面助手与学业全能智能体。
100% 对齐 Android 移动端与 PC 桌面端全量功能，基于现代化 **Swift 5.9+、SwiftUI、ActivityKit（灵动岛与锁屏实时活动）、WidgetKit 桌面小组件与 EventKit 日历生态** 原生开发。

---

## 🌟 核心特性与架构实现

1. **罗德岛 AI 指挥室 (Chat & Assistant)**：
   - **交互式顶栏阿米娅桌宠**：内置触摸互动、拖拽弹性、打盹与专注差分立绘，搭载 35 款官方无损中文原声。
   - **DeepSeek-R1 深度思考链**：原生支持流式打字机与思维链抽屉折叠展开（`reasoning_content`）。
   - **自然语言指令智能拦截**：对话中直接添加课程、删除课程、启动番茄钟、速记备忘，自动生成战术交互卡片。

2. **自适应全景课表 (Schedule Timetable)**：
   - **7 天 13 节一屏全览**：无缝完整展示全天排课，无课时段规整留空，彻底消除上下滑动。
   - **智能调课与节假日停课覆盖层**：支持中秋国庆连休停课与跨周换课（如“按第5周周二执行”）精准映射。
   - **AI 多模态拍照识图导入**：集成系统相册与相机，调用智谱 GLM-4V 多模态网格大模型一键提取课程信息。
   - **系统级双向日历同步**：支持一键直达写入 Apple 原生「日历」应用，或导出 RFC 5545 标准 `.ics` 文件。

3. **Apple 专属杀手级体验：灵动岛与锁屏实时活动 (Live Activity & ActivityKit)**：
   - **正在上课实时动态卡片**：上课期间自动在 iPhone 灵动岛（胶囊/长按展开）与锁屏展示实时进度条、倒计时与下节课教室预告。
   - **番茄钟专注环形活动**：专注自习时灵动岛分秒常驻倒计时，配合绝对时钟保证熄屏不停止。

4. **沉浸式战术专注 (Pomodoro)**：
   - 环形炫彩进度仪表盘、伴学阿米娅专注状态立绘、多档时长预设（15/25/45/60分钟）与工作/休息流转。

5. **战术便签本 (Notes)**：
   - 灵感随记、首行智能提取标题、置顶管理、全文实时检索与跨设备剪贴板同步。

6. **期末统考大看板 (Exams)**：
   - 考试科目、倒计时 D-Day 药丸徽章、考场地点、座位号、临考 24 小时紧急警示与表情差分联动。

7. **干员衣橱与跨设备互联 (Wardrobe & LAN Sync)**：
   - 术师·庆典、近卫·影霄、见习联络员·报童三套形态立绘随时自由换装。
   - 局域网 UDP 组播发现与 HTTP/TCP 快传，与 Windows PC 桌面端、Android 手机端跨端联动。

## 🛠️ 本地开发与运行 (macOS & Xcode)

### 环境要求
- **macOS**：macOS 14 (Sonoma) 或更高版本
- **Xcode**：Xcode 15.0+ / Xcode 16.0+
- **目标设备**：iOS 16.1+ (iPhone / iPad)

### 快速打开与调试
1. 在 Mac 上使用 Xcode 打开本项目目录下的工程文件：
   ```bash
   open ios/AmiyaPet.xcodeproj
   ```
2. 在 Xcode 顶栏选择目标设备（例如 `iPhone 15 Pro` 模拟器或真实 iPhone 真机）。
3. 点击 **Run (Cmd + R)** 即可一键编译并在设备上运行！

### 自动化构建 (CI/CD)
本项目已在 `.github/workflows/ci.yml` 中集成基于 GitHub Actions `macos-14` 虚拟机的全自动化构建流水线。每次推送提交或发布版本标签（如 `v1.9.4`）时，GitHub 将自动编译生成未签名的测试包 `AmiyaPet-iOS-*.ipa` 与 `.zip` 并自动发布至 GitHub Releases 附件。
